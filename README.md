# 📊 Telegram-бот для мониторинга оборудования

Telegram-бот, предназначенный для фиксации работы оборудования в режиме реального времени. Бот позволяет вести учет остановок и запусков, рассчитывать время простоя и работы, а также автоматически формировать подробные Excel-отчеты.

## ✨ Основные возможности

- **Учет событий:** Фиксация остановок (с указанием причины) и запусков оборудования.
- **Совместная работа:** Возможность делиться мониторингом с коллегами по уникальному коду доступа.
- **Разграничение прав:** Роли администратора и обычного пользователя. Новички могут пользоваться ботом только после одобрения заявки администратором.
- **Фотофиксация:** Возможность прикреплять фотографии к событиям (до 10 фото на сессию).
- **Excel-отчеты:** Автоматическая генерация файлов `.xlsx` с тремя листами: «Сводка», «События» и «Фотографии».
- **Комментарии:** Возможность оставлять текстовые заметки по времени, не влияющие на статистику простоев.

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Фреймворк:** aiogram 3.x
- **База данных:** SQLite (встроенная)
- **Генерация отчетов:** openpyxl
- **Работа с изображениями:** Pillow
